# Serveur multijoueur de battleWorld

Petit relais WebSocket : il relie les joueurs d'un même salon (5 au plus). Il ne contient aucun fichier du jeu.

Sur Render (service web gratuit) :
- Runtime : Python 3
- Build command : `pip install -r requirements.txt`
- Start command : `python relay.py`

En local : `python relay.py` (port 8765).
